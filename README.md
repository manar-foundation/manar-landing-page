# صفحة هبوط — إعلان تعيين ميسر/ة تدريبات

صفحة هبوط من صفحة واحدة (SPA) مبنية بـ **React + Vite**، تعرض إعلان التعيين الخاص
بمؤسسة منار للمشاركة المجتمعية، وتنتهي بزر تقديم يوجّه إلى نموذج الطلب.

- الهوية البصرية مستوحاة من الموقع الأساسي: <https://www.manar.org/ar>
- الخط المستخدم: **Readex Pro** — وهو الخط نفسه المعتمد في موقع المؤسسة وفي ملف الإعلان.
- الصفحة بالكامل **RTL** وعربية، ومتجاوبة مع جميع المقاسات.

---

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح <http://localhost:5173>

| الأمر             | الوظيفة                          |
| ----------------- | -------------------------------- |
| `npm run dev`     | تشغيل خادم التطوير               |
| `npm run build`   | بناء نسخة الإنتاج في `dist/`     |
| `npm run preview` | معاينة نسخة الإنتاج محلياً       |
| `npm run lint`    | فحص الكود                        |

## تعديل رابط التقديم

جميع أزرار التقديم في الصفحة (الترويسة، الواجهة، لوحة التقديم) تقرأ من متغيّر واحد.
لتغيير الرابط لاحقاً عدّل **سطراً واحداً فقط** في [`src/content.js`](src/content.js):

```js
export const APPLY_URL = 'https://forms.gle/HWW6WpUtPW3wWz1T6'
```

ولوضع رابط مؤقت ريثما يُعتمد الرابط النهائي:

```js
export const APPLY_URL = '#'
```

> الرابط الحالي هو الرابط الوارد نصّاً في ملف الإعلان المرفق.

## المحتوى

جميع النصوص منقولة **حرفياً** من ملف `إعلان تعيين ميسر/ة تدريبات.docx`
دون زيادة أو نقصان أو تعديل في الصياغة، وهي مجمّعة كلها في ملف
[`src/content.js`](src/content.js) لتسهيل أي تحديث لاحق.
